# 🌱 Habitly

**Build better habits, one day at a time.**

Habitly is a static habit-tracking dashboard developed as part of the CodGen Frontend Development Internship – Week 1 assignment.

## Features

- Clean and modern dashboard design
- Three daily and weekly summary statistics
- Five habit cards with emojis and streak indicators
- Responsive layout for mobile, tablet and desktop
- Hover effects on cards and buttons

## Technologies Used

- HTML5
- CSS3
- Google Fonts (Inter)
- CSS Grid and Flexbox
